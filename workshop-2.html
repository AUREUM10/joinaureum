Claude Code: Build & Launch Your Own App

That business idea you've been sitting on? Let's build it.

You have an idea for an app, a client portal, a booking system or a tool that would make running your business easier.

But turning that idea into software sounds complicated. You don't know how to code. Hiring a developer is expensive. And learning programming isn't exactly at the top of your to-do list.

What if you could build the first version yourself?

With Claude Code, you can describe what you want to create, guide the development process and see your ideas turn into working software.

You don't need to become a programmer. You do need to learn how to think through an idea, give clear instructions, test the results and make good decisions. We'll teach you exactly that.

In one day, you'll go from an idea to a working first version of your own application, with the goal of getting it online at a link you can share.

What you’ll learn

01

Turn an idea into a buildable plan

Great software starts with knowing what problem you're solving.

We'll help you choose a realistic project, define what it should do and create a clear plan for its first version.

You'll learn how to explain your idea to Claude Code so that it understands what to build, without getting lost in unnecessary complexity.

02

Build software with AI

Now your idea starts taking shape.

You'll learn how to use Claude Code to create an application, make changes, fix mistakes and improve the design.

We'll introduce the terminal in simple language, show you exactly what to do and help you understand what's happening as your app is built. No prior coding knowledge required.

03

Make your application actually work

A beautiful screen is a start. A useful application needs to do something.

Depending on your project, you'll learn how to add forms, store information, display data and create simple user interactions.

We'll introduce tools such as Supabase for storing data and managing user accounts, without expecting you to write everything yourself.

04

Put your application online

Your idea shouldn't stay hidden on your laptop.

You'll learn how to save your project using GitHub and publish it with Vercel, so your application can be opened in a browser.

We'll explain the difference between testing something privately and making it available to real users.

05

Learn how to keep building after the workshop

Building with AI is not about getting everything right on the first try.

You'll learn how to spot problems, ask Claude to fix them, review what it creates and avoid common security mistakes.

We'll also show you how to use skills, plugins and other tools to speed up future development.

What could you build?

Your project should be small enough to complete a useful first version in one day. Some ideas:

  • Client management tool: Keep track of clients, enquiries and follow-ups.
  • Booking application: Let people request appointments or services.
  • Customer intake portal: Collect information through a form and organise it in one place.
  • Business dashboard: Bring important information together in a simple interface.
  • Reporting tool: Turn recurring information into a report you can generate again and again.

Already have an idea? Bring it. We'll help you make it realistic.

What you’ll leave with

By the end of the workshop, you'll have:

  • A clear plan for your application
  • A working first version built with Claude Code
  • Your project saved in GitHub
  • A shareable test link for your application
  • The confidence and practical knowledge to continue improving it independently
  • A collection of useful instructions and resources for future projects

One important distinction: you'll build a working first version, not a fully developed commercial product. Some projects will need additional work, testing and security checks before real customers can use them.
